Web Security Architecture

Adaptive Shield: Protecting Authentication Surfaces on Modern Websites

Modern web platforms face persistent automated brute-force scripts and distributed credential stuffing attacks targeting user login endpoints. Relying solely on a password check is catastrophic. This project explores the mathematical and architectural implementation of a progressive, layered mitigation framework designed to defeat bot armies without degrading legitimate user experience.

01. Token-Bucket Rate Limiting

Limits request bursts using memory-resident counters (Redis) per IP and account hash, throttling non-human velocity.

02. Progressive Delay (Tarpitting)

Systematically inflates backend response latency exponentially (+500ms, +1500ms) after repeated failed attempts to starve bot concurrency.

03. Risk-Based CAPTCHA Spawning

Dynamically injects frictionless invisible challenges (Cloudflare Turnstile / reCAPTCHA v3) only when risk scores cross threshold.

04. Dynamic IP Quarantine & WAF

Integrates with Fail2Ban and Cloudflare Edge WAF to drop malicious connection sockets at the network perimeter.
